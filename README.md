# SUBBU

ติดตามค่าสมาชิก บิล และค่างวด เป็นเงินบาทหรือดอลลาร์ พร้อมเตือนก่อนตัดเงิน ใช้ได้ทั้งภาษาไทยและอังกฤษ และติดตั้งบนมือถือได้ (PWA)

Track subscriptions, bills and loan payments in THB or USD, with reminders before each charge. Thai and English. Installable on phones as a PWA.

## Files

| File | Purpose |
|---|---|
| `src/app.html` | App source. Edit this, then run the build. |
| `index.html` | Built app. Generated by `build.js`, don't edit by hand. |
| `manifest.webmanifest` | App name, icons and home-screen shortcut. |
| `sw.js` | Service worker for offline use. Its cache version is stamped by the build. |
| `icons/` | App icons. |
| `build.js` | `node build.js` builds `index.html` from `src/app.html`. |
| `serve.js` | `node serve.js` serves the app at http://localhost:5173 for testing. |

## Update the live site

```bash
node build.js
git add -A
git commit -m "Describe the change"
git push
```

GitHub Pages republishes within a minute or two. Installed copies pick up the new version the next time they're opened online.

## Data

Data is stored in the browser of each device (localStorage). It does not sync between devices yet.
